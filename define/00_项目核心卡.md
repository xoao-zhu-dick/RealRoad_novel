  ## 2. 一句话故事 + 第一集钩子

  ### 一句话故事

  25岁的吴谓在科技展设备故障中救了13岁的杜淼，自己被波及获得空间转换能力；他随后发现每个异常事件都对应一份档案原型，而杜淼负责查资料却总撞上[数据删除]式的信息屏蔽——两人只能靠“吴谓亲历 + 杜淼记录”拼出真相。

  ### 第一集钩子

  科技展设备故障后，现场留下一份不该存在的电子档案碎片：异常名称和异常类型字段还在，但关键内容被[数据删除]覆盖。吴谓发现这份档案和他刚经历的事对得上，而杜淼查到的资料总在同一个地方断掉。片尾，同一份档案自动出现在吴谓手机上，最后一行是：`记录状态：已修复 / 影响已清除 / 目击者：0`。

  # 双主角功能卡

## C01 · 吴谓

### 基本信息

| 项     | 内容                                         |
| ------ | -------------------------------------------- |
| 年龄   | 25                                           |
| 身份   | 科技有限公司员工，科技展参展（非FX-7公司）   |
| 知道   | 科学、计算机、哲学                           |
| 不知道 | 暂时不揭示（观众随剧情逐步发现他的认知盲区） |
| 最怕   | 怕修完异常后连杜淼也不记得这件事             |

### 能力：双能力，都只在异常附近触发

**能力一：空间转换（机器拟人化 + 直接交流）**

- **是什么**：能把机器/设备看成一种**拟人化的抽象形态**，并与之直接交流。
- **触发条件**：只在异常附近触发。离开异常范围，机器在他眼里就是普通机器，无法交流。
- **首次触发**：第一集故障时被动触发——FX-7在他眼里“活”了过来（拟人化抽象形态），他本能地跟它交流，随后两人被挪开、设备停机。
- **主动使用**：需后续集数逐步学习。
- **代价**：**按解决异常的数量累积**——每解决一个异常，吴谓本人就从所有人的记忆里淡出一层；解决得越多，记得他的人越少。与“修复异常后事件被遗忘”叠加，最终可能没人记得他这个人。

**能力二：数据转移/读取**

- **是什么**：能“读”到异常相关的损坏/被删数据，并原封不动转移到自己设备上。
- **触发条件**：同样只在异常附近。
- **数据形态**：损坏=`▮`；被人为删除=`[数据删除]`/`[/已编辑]`。转移成功后数据以完整原貌出现，不带标记。
- **代价**：转移留下痕迹，但FX-7检测设备读不懂`▮`，判定为无效数据。

### 代价总表

| 能力                 | 代价                                                         |
| -------------------- | ------------------------------------------------------------ |
| 空间转换（机器交流） | 按解决异常数量累积，吴谓本人逐渐被所有人遗忘                 |
| 数据转移             | 留下痕迹被检测（对方读不懂`▮`）                              |
| 修复异常（共同）     | 渐进遗忘：修复一点，事件细节模糊一点；修复完成，事件从所有人记忆里清除，只有吴谓记得 |

### 三条规则

1. **异常依赖**：两种能力都只在异常附近触发，离开即失效。
2. **被动优先**：第一次触发都是被动/本能，主动控制需后续学习。
3. **遗忘双线**：机器交流让“吴谓本人”按解决异常数量被遗忘；修复异常让“事件”被遗忘。两条线叠加，杜淼的记录是唯一外部锚点。

## C02 · 杜淼

### 基本信息

| 项     | 内容                                               |
| ------ | -------------------------------------------------- |
| 年龄   | 13                                                 |
| 身份   | 学生，科技爱好者，混入科技展                       |
| 知道   | 记录习惯、基础查证能力、对机器逻辑有直觉           |
| 不知道 | 不知道FX-7异常，只好奇它的逻辑                     |
| 最怕   | 出错（记错、漏记、判断错，导致吴谓或自己陷入危险） |

### 功能：记录 + 查证 + 锚定（无异常能力）

**功能一：记录**

- **是什么**：把看到的、查到的现象以字段形式记在平板里（异常名称、类型、现象、时间、位置）。
- **怎么用**：吴谓修复异常后事件被遗忘，杜淼的记录是唯一能证明“这件事发生过”的外部证据。
- **限制**：记录会被FX-7公司回收/删除；他只能靠手写备份和记忆补录。

**功能二：查证**

- **是什么**：查资料、比对信息、发现数据缺口。
- **怎么用**：查FX-7型号时撞上[数据删除]覆盖块，形成“现象记录”与“被删资料”之间的缺口，这个缺口本身就是解密线索。
- **限制**：13岁，权限和体力不足；查证速度慢，危险时容易慢半拍。

**功能三：锚定**

- **是什么**：给吴谓提供“人味”和外部记忆。
- **怎么用**：吴谓被遗忘时，杜淼是唯一记得“吴谓做过什么”的人；吴谓判断失控时，杜淼用记录把他拉回现实。
- **限制**：他自己也会被卷入遗忘机制，只是比旁人慢；他的记录一旦被删，锚点就断了。

### 代价/限制总表

| 功能 | 代价/限制                                    |
| ---- | -------------------------------------------- |
| 记录 | 记录会被回收/删除，需手写备份                |
| 查证 | 权限不足，速度慢，危险时慢半拍               |
| 锚定 | 他自己也会被遗忘机制波及；记录被删则锚点断裂 |

### 三条规则

1. **先记再反应**：危险时他会先看平板再抬头，这个习惯既是优势也是弱点。
2. **记录即证据**：他的记录是唯一能对抗“修复即遗忘”的外部锚点。
3. **不解释机制**：他不懂异常原理，只记现象，不替观众解释设定。

---

## 两人同框规则

1. **对话有信息差**：吴谓说“为什么”，杜淼说“记了什么”；吴谓给解释，杜淼给现象。
2. **动作上吴谓先动、杜淼后动**：吴谓冲出去，杜淼低头记录或查证。
3. **情感上杜淼先软化、吴谓后承认**：杜淼会直接说“你刚才救了我”，吴谓只会说“你没事吧”。
4. **禁止**：两人同时说同一类话；杜淼变成纯解说；吴谓变成纯打手。

  ## 5. 解密引擎与档案碎片规范

  ### 解密引擎

  - **主引擎**：档案碎片。每集片尾呈现一份电子档案，字段固定，关键内容常被[数据删除]覆盖。
  - **辅助引擎**：杜淼查资料时遭遇信息屏蔽，形成“现象记录”与“被删资料”之间的缺口。
  - **观众获取方式**：片尾固定呈现，与主角同步拼图。

  ### 档案形态

  - **形式**：电子形式（屏幕、终端、平板、投影皆可，统一视觉语法）
  - **视觉基调**：冷色终端感，字段整齐，参考《视觉风格宪章》电子档案UI规范

  ### 固定字段

  每份档案碎片固定包含：

    1. **异常名称**
    2. **异常类型**（具体分类看异常本身，后续定一套原创类型表）
    3. **关键内容**——常被[数据删除]覆盖，是解密缺口所在

  ### 观众获取方式

  - **片尾固定呈现**：每集片尾给一份碎片，观众和主角同步拼图。
  - **视觉仪式**：固定电子UI模板，形成“每集必看片尾”的仪式感。
  - **删除标记**：被删字段用统一的撕裂/噪点遮挡视觉标记，让观众一眼认出“这里有坑”。

  ### 档案与设备的关系

  - 档案不是外挂，是异常设备/事件行为的残留。
  - KX-7每次执行修正会生成修正记录，故障后记录被远程清除，只留残缺碎片。
