# U00 · 迁移进度UI

## 简述

- **类型**：界面
- **首次出现**：前传 场1 危机室大屏
- **用途**：呈现FX-8pre迁移进度与“中心区域被占用”状态，全剧复用

## 描述

冷色数据可视化界面，深灰蓝底。主体为规则的矩形服务器模块阵列，蓝色光带在矩形模块之间穿梭（代表数据流传输）。中心区域有一个高亮的巨大矩形模块，以红点闪烁标记，旁附系统提示文字：`目标区域被占用 / 迁移暂停`。界面下方有进度条和节点列表，字体等宽。整体与U01档案UI同一视觉语法。
